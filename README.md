# ЛР № 1. Апроксимація функцій методами інтерполяції та МНК

Веб-застосунок на JavaScript (Canvas 2D, без зовнішніх бібліотек), який будує
інтерполяційний поліном Лагранжа (з таблицею поділених різниць Ньютона) і МНК-апроксимацію
(QR-розклад Хаусхолдера) з анімацією та **автоматичним масштабуванням осей X і Y**.

**Варіант:** (0; 0.0), (1; 0.5), (2; 0.8), (3; 0.5), (4; 0.0). Набори на 10 і 20 точок
згенеровано на тому ж відрізку за формою варіанта (`scripts/gen-datasets.js`).

## Запуск

- Відкрити `index.html` у браузері (подвійне клацання — сервер не потрібен).
- Тести: `npm test` (Node.js ≥ 18; браузерні тести UI виконуються, якщо встановлено Playwright: `npm i -D playwright`).
- Аналітичне тестування: `npm run bench` → `docs/analysis.md`.
- Скріншоти для звіту: `node scripts/screenshots.js` (потрібен Playwright).

## Можливості

- Перемикання наборів 5 / 10 / 20 (кнопки або клавіші 1 / 2 / 3) — миттєве порівняння.
- Режими «Інтерполяція / МНК / Усі», степінь МНК m = 1…6, нормалізація x, зона екстраполяції, еталонна форма.
- Анімація Лагранжа (покрокове додавання вузлів, активний вузол виділено) і МНК («вирощування» від ȳ, поява залишків).
- Діаграма залишків, підказки при наведенні, метрики (SSE, RMSE, R², max|r|, cond₂), таблиця поділених різниць.
- 6 мініграфіків (3 — Лагранж, 3 — МНК) і порівняльна таблиця для 5/10/20 точок.

## Структура

```
index.html            інтерфейс
css/style.css         стилі (світла/темна тема)
js/datasets.js        набори 5/10/20
js/approx.js          математичне ядро (Лагранж, Ньютон, МНК-QR, метрики)
js/scale.js           автомасштаб осей
js/chart.js           рендерер Plot (Canvas 2D)
js/app.js             контролер: стан, анімація, події
tests/                модульні (node:test) та UI-тести (Playwright)
scripts/              генератор наборів, бенчмарк, скріншоти
docs/                 ТЗ, методологія, ідентифікатори, діаграми, аналіз, AI-лог
```
