# Технічне завдання (ТЗ)

**Проєкт:** веб-застосунок «Апроксимація функцій методами інтерполяції та МНК» (ЛР № 1).
**Методологія:** V-модель (див. [methodology.md](methodology.md)).

## 1. Призначення

Програма будує за табличними даними {(xᵢ, yᵢ)} інтерполяційний поліном Лагранжа (з таблицею
поділених різниць у формі Ньютона) і МНК-апроксимацію поліномом степеня m, анімує побудову,
показує залишки та метрики і дає змогу миттєво порівнювати результати для 5, 10 і 20 точок.

## 2. Вхідні дані

| Набір | Джерело | Вузли |
|---|---|---|
| 5 точок | індивідуальний варіант | (0; 0.0), (1; 0.5), (2; 0.8), (3; 0.5), (4; 0.0) |
| 10 точок | згенеровано `scripts/gen-datasets.js` | xᵢ = 4i/9, yᵢ = g(xᵢ) + ε, ε ∈ [−0.03; 0.03] |
| 20 точок | згенеровано `scripts/gen-datasets.js` | xᵢ = 4i/19, yᵢ = g(xᵢ) + ε |

g(x) = 0.8 − (x−2)²/3 + (x−2)⁴/30 — інтерполяційний поліном варіанта (базова форма, «еталон»).
Набір можна замінити у формі: «(x, y), (x, y), …» або по рядку «x y».

## 4. Вимоги до інтерфейсу

- Адаптивне полотно (ResizeObserver, devicePixelRatio), робота від 360 px ширини без горизонтальної прокрутки.
- Осі з підписами та «гарними» поділками (1·10ᵏ, 2·10ᵏ, 5·10ᵏ), сітка, легенда.
- Контрастні кольори кривих: Лагранж — синій, МНК — помаранчевий, залишки — фіолетовий, активний вузол — червоний; світла і темна теми.
- Усі елементи керування — в одному рядку над графіком.

## 5. Обмеження

- Вузли xᵢ попарно різні, щонайменше 2 точки; m ≤ n − 1 (інакше система недовизначена).
- Глобальний поліном Лагранжа високого степеня на рівновіддалених вузлах осцилює (ефект Рунге) —
  це властивість методу, а не помилка; програма показує її через автомасштаб.
- Чисто клієнтський застосунок без сервера і зовнішніх бібліотек; працює при відкритті `index.html` файлом.

## 6. Нефункціональні вимоги

- Чисельна стійкість: нормалізація x → t ∈ [−1; 1], QR замість нормальних рівнянь.
- Продуктивність: перерахунок моделі й кривих < 1 мс для n ≤ 20; анімація 60 кадр/с.
- Якість: автоматизовані тести (`npm test`), аналітичне тестування (`npm run bench`).
