# Журнал розробки (фактичні проблеми, виявлені під час роботи)

1. **Оцінка обумовленості через діагональ R (помилка AI).** Перша версія `leastSquares`
   повертала `condR = max|R_ii| / min|R_ii|` як «оцінку числа обумовленості». Тест Т-12
   показав, що ця величина для ненормалізованого x (1.49) навіть менша, ніж для
   нормалізованого (43), тобто вона не відображає обумовленість. Виправлення: функція
   `conditionNumber(A)` — σmax/σmin через власні значення AᵀA методом обертань Якобі
   (+ тест Т-16 на відомих матрицях). Тепер для m = 6, n = 20: 1.7·10⁵ без нормалізації
   проти 92 з нормалізацією.
2. **Неправильні «ручні» еталони в тестах (помилка AI).** У тестах Т-03 і Т-08 AI спершу
   вписав хибні очікувані значення (p(1.5) = 0.7354 замість 0.71875; коефіцієнти
   квадратичної МНК-моделі −1/35, 47/70, −5/28 замість −2/175, 26/35, −13/70).
   Перерахунок вручну (симетрія даних відносно x = 2, заміна s = (x−2)²) підтвердив
   правильність коду, а не тестів; виправлено очікувані значення.
3. **Колізія селекторів (помилка AI).** Обробники кнопок режиму навішувалися через
   `querySelectorAll('[data-mode]')`, але атрибут `data-mode` має й `<body>` (він
   перемикає легенду через CSS). У результаті будь-яке клацання на сторінці викликало
   `setMode('all')` і зупиняло анімацію одразу після натискання «Анімувати». Виявлено
   під час перевірки в браузері (Playwright: `state.anim === null` через 0.5 с після
   старту, стек виклику вказав на `HTMLBodyElement`). Виправлення: селектори
   `button[data-mode]` і `button[data-n]` (атрибут `data-n` мають і мініграфіки).
